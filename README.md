# 🌍 Global Analytics Dashboard

An interactive data visualization dashboard built using Streamlit, Plotly, and Pandas to analyze global economic and population trends using the Gapminder dataset.

---

## 🚀 Live Demo

[View Live App](https://your-streamlit-app-url.streamlit.app)

---

## 📌 Features

- 🌎 Continent and country filters
- 📈 GDP per capita trend analysis
- 👥 Population growth visualization
- ❤️ Life expectancy insights
- 📊 Interactive Plotly charts
- 📋 Downloadable filtered datasets
- 🎨 Modern responsive dashboard UI

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Python | Backend Logic |
| Streamlit | Web Application Framework |
| Pandas | Data Processing |
| Plotly | Interactive Visualizations |

---

## 📂 Dataset

This project uses the built-in Gapminder dataset provided by Plotly.

Dataset includes:
- Country
- Continent
- Population
- GDP Per Capita
- Life Expectancy
- Year
